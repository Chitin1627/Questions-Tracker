# Questions Tracker App
This Android app helps you track the number of coding problems solved on various platforms like LeetCode, Codeforces, CodeChef, and others. Built using Kotlin and Jetpack Compose, the app features a local SQLite database for data storage and provides visual and statistical insights into your coding activity.

## Features
  1) **Local SQLite Database:** Stores no. of questions solved for each day and each platform.
  2) **Home Screen:** Displays a pie chart with the distribution of questions solved across different platforms.
  3) **Stats Screen:** Shows current streak, highest streak, total days tracked, and questions solved in the last 30 days.
  4) **Daily Tracker:** Allows users to input and view the number of questions solved for each day.

## Tech Stack
  1) **Frontend:** Kotlin, Jetpack Compose
  2) **Database:** SQLite
